# production-dashboard

React + Vite + Tailwind CSS dashboard application.

## Development server

Use the standard Vite workflow:

- `npm install`
- `npm run dev`
- `npm run build`

## Project structure

- `src/main.tsx` - React entrypoint that mounts the app into `#root`
- `src/App.tsx` - main dashboard component
- `src/index.css` - global styles and Tailwind import
- `index.html` - Vite HTML shell
- `package.json` - scripts and dependencies
- `vite.config.ts` - Vite configuration with React and Tailwind

## Code quality

- Keep code simple and readable
- Use double quotes for strings with apostrophes where needed
- Ensure JSX tags are properly closed and balanced
- Export components as default exports
